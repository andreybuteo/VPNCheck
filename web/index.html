Справка и ограничения

Программа проверяет доступность контрольных узлов, а не гарантирует работу приложений. Доступность страницы YouTube не доказывает воспроизведение видео, доступность доменов Fusion — сохранение проекта, TLS к API — успешный вызов модели. Ответ 401 означает «сервер ответил, требуется авторизация», а не «API работает».

Типы проб: tls — DNS → TCP 443 → TLS с проверкой сертификата, без HTTP-запроса; https — один GET к небольшому документированному ресурсу, все этапы измеряются на этом же запросе. Редиректы не выполняются, повторов нет, тело ограничено 64 КиБ.

Щадящие лимиты: не более 4 проб одновременно, одна на хост, пауза между запусками (настраивается, по умолчанию 60 с), стоп хоста после 403/CAPTCHA до конца запуска, пауза после 429 по Retry-After или 15 минут. Это осторожная настройка приложения, а не квота сервисов; нулевой риск блокировки не обещается.

Закрытие вкладки не завершает программу: backend продолжает работать, и повторный запуск VPNCheck.exe снова откроет этот интерфейс. Чтобы остановить процесс и освободить порт, нажмите «Завершить приложение».
