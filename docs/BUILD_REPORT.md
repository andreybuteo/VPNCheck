## Проверка интерфейса

Выполнена во встроенном браузере приложения Claude Code (Chromium) на сборке с флагом `--demo`
(подставные результаты, без сетевых запросов, отдельный каталог данных, баннер «ДЕМО-РЕЖИМ»):

- 1366×768: шапка, чипы групп, сводка, карточки и история помещаются без горизонтального скролла
  (`scrollWidth == clientWidth`); 700 px: карточки перестраиваются в 3 колонки, плитки в 2.
- Тёмная и светлая темы, переключение сохраняется в настройках.
- Запуск → прогресс по SSE (очередь, текущий этап, «Остановить») → завершение; отмена: активные
  пробы завершаются, ожидающие получают состояние «отменено», запуск сохраняется как «Отменён».
- Карточка → таблица деталей → раскрытие строки с пояснением и технической причиной.
- Режим «Стабильность» (2 узла × 3 пробы): строки по попыткам и статистика min/median/max.
- История: два запуска, сравнение с примечаниями о маршруте и метрике, экспорт JSON (attachment,
  `schemaVersion: 1`) и CSV, краткий итог без IP и адресов прокси.
- Панель настроек: обнаружен системный прокси WinINET `127.0.0.1:10809` и переменные окружения,
  кнопка «Применить», предупреждение в шапке о различии пути браузера и программы.
- «Завершить приложение»: процесс завершён, порт освобождён, `instance.json` удалён; повторный
  запуск exe при работающем экземпляре открывает вкладку к нему, а не второй сервер.
- Ошибок в консоли браузера после исправлений нет; CSP без inline-стилей и скриптов.

Не проверено вручную: ввод с клавиатуры в каждом элементе (проверен фокус, Escape для панели и
деталей, строки таблицы реагируют на Enter/Space по коду).

## Что ещё требуется

Smoke-test реальной сети выполнен один раз через локальный прокси с разрешения пользователя
(см. раздел ниже). Прямой маршрут (TUN) на этой машине не проверялся: VPN здесь работает как
локальный прокси, а не как TUN-адаптер. Ограничитель приложения (4 параллельно, 12 проб/час на
хост, cooldown 60 с) действовал и для этого теста.

Не проверялось на реальной сети: путь IPv6 (тесты покрывают фильтр семейства и Happy Eyeballs
логику локально, но не двухстековую внешнюю сеть), реальные ответы 429/403 сервисов, поведение
за реальным SOCKS5/CONNECT прокси с удалённым DNS (проверено на локальных тестовых прокси).
